# Curated audio assets

Add only original, public-domain, or appropriately licensed audio here. No playable tracks are currently included.

Use one directory per scheduled genre:

- `indie/`
- `electronic/`
- `hip-hop/`
- `pop/`

The music catalogue must reference the public URL, for example `/audio/indie/track-id.mp3`. A catalogue entry is not shown to visitors unless it is marked available and has both an audio path and a prepared beatmap reference.
